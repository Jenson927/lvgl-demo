LVGL Lottie 本地复刻

用 Canvas 模拟 Lottie 矢量动画（脉冲同心圆 + 旋转星形 + 进度条），展示 JSON 关键帧经像素缓冲交给 lv_lottie 渲染的流程，速度与循环实时可调。

参数（对应 LVGL 接口）

关闭后播放一轮即停在末帧
播放中 · 2.00 s / 轮
animation.json → 图层树解析 → 像素缓冲（ARGB8888）→ lv_lottie 逐帧渲染


  
画布尺寸 320×240。GIF 编码由 gif.js（jsDelivr CDN）完成，需联网；WebM 使用浏览器原生 MediaRecorder，离线可用。
